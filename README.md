# Compteur de Clics

Un projet simple pour apprendre JavaScript.

## Description

Ce projet est un compteur interactif qui permet d'incrementer, décrémenter et réinitialiser un compteur.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript ES6

 ## Installation

1. Cloner le dépôt : `git clone <url-du-repo>`
2. Se déplacer dans le dossier : `cd le-compteur-maudit`
3. Ouvrir `index.html` dans votre navigateur

## Fonctionnalités

- Bouton + pour augmenter
- Bouton - pour diminuer
- Bouton reset
